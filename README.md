# Buffett Portfolio Example

This repository contains a simple Python script to calculate the value and weights of holdings in Warren Buffett's (Berkshire Hathaway) portfolio. It includes a function for a simplified Graham intrinsic value calculation.

## Usage

Run the script with Python 3:

```bash
python3 buffett_portfolio.py
```

The output will display the value of each holding, their weight in the portfolio, the total portfolio value, and an example intrinsic value calculation.
